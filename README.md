# nushbus: NUSH Bus Timings
nushbus is a simple [website](https://gohjy.github.io/nushbus) to display the bus arrival timings at several bus stops around NUSH. It is intended as a user-friendly alternative to [appventure-nush's bustimings-2](https://github.com/appventure-nush/bustimings-2).
